# Алаг мэлхий — VS Code дээр ажиллуулах

1. ZIP файлыг задлана.
2. VS Code → File → Open Folder → Alag-Melhii хавтсыг сонгоно.
3. Extensions хэсэгт **Live Server** (Ritwick Dey) өргөтгөлийг суулгана.
4. index.html дээр хулганы баруун товч → **Open with Live Server**.

Шууд index.html файлыг давхар дарж нээхэд 3D загвар ачаалахгүй байж болно. Live Server-ээр нээнэ.

Live Server ашиглахгүй бол Python суулгасан үед VS Code Terminal дээр:

```sh
python -m http.server 5500
```

Дараа нь http://localhost:5500 дээр нээнэ.

## Файлууд

- index.html — интерфейс
- style.css — өнгө, дэвсгэр, шооны анимацын хэв маяг
- game.js — шагайн байрлал, эргэлт, тоглох дүрэм, 3D дүрслэл
- bone.json — өгсөн OBJ-оос гаргасан хөнгөн 3D тор
- original-shagai.obj — таны өгсөн эх загвар
- vendor/ — Three.js болон MediaPipe гар таних загвар; интернетээс ачаалах шаардлагагүй

Шагайн байрлалыг game.js доторх point(x, y, height, rotation) утгуудаар өөрчилнө. rotation нь радиан; Math.PI нэмэхэд 180° эргэнэ.

Нэг төхөөрөмж дээр 1–12 тоглогч ээлжээр тоглоно. Шоо хаяж, тодорсон эрхтэн эсвэл нэрийг сонгож авна.

## Камераар шоо хаях

«Камераар шоо хаях» товчийг дарж камерын зөвшөөрөл өгнө. Камераа гарынхаа хажууд байрлуулж, гар болон шидэх зам нь бүтнээр харагдахаар тохируулна. Шоо барьсан мэт хуруугаа хумиад, шоо шидэх мэт гараа хурдан савж хуруугаа суллахад шоо хаяна. Зүгээр гараа хөдөлгөөнгүй дэлгэхэд хаяхгүй. Дахин хаяхын өмнө шоо барих мэт хуруугаа дахин хумьж бэлдэнэ. «Камер унтраах» товч камераа зогсооно. Шагай сонгох үед гарын хөдөлгөөнөөр дахин шоо хаяхгүй. Камергүй бол «Шоо хаях» товчоор тоглож болно.

Камер нь HTTPS эсвэл localhost дээр ажиллана. VS Code Live Server энэ шаардлагыг хангана. Камерын дүрс төхөөрөмж дээр боловсруулагдана.

Буусан тооны бүлэг өрөгт байхгүй бол тухайн тоглогч өөрийн нийт шагайнаас буцааж өрнө. Тэр бүлгийг өмнө нь авсан байх шаардлагагүй. Нийт шагай нь хүрэлцэхгүй бол тоглоомоос хасагдаж, дараагийн ээлжүүдийг алгасна. Нэг тоглогч үлдвэл хожно.

Шоо хаях анимацтай зэрэг өнхрөх, буух дуу тоглоно. dice-audio.js дотор дууг төхөөрөмж дээр үүсгэнэ.

## Морь уралдуулах

Эхлэх дэлгэц эсвэл дээд цэсний **Морь уралдуулах** сонголтоор орно.

- 1–12 тоглогч, 12 / 18 / 24 шагайн замтай.
- Дөрвөн шагай хаяна. Буусан морины тоогоор явна; морьгүй бол өнжинө.
- Морь, хонь, ямаа, тэмээ тус бүр нэг буувал дөрвөн бэрх: 4 урагшилна.
- Эхний хаялт бусад хаялттай адил. Эргэх алхам байхгүй.
- Алаг мэлхийн гэр, олбог дэвсгэр, шагайн 3D загвар болон материал ашиглана. Замын шагай хөх ногоон, уралдах шагай өнгөтэй. Камер эгц дээрээс харна.
- **Камераар шагай хаях**: гараа атгаж бэлдээд, шидэх мэт савж хуруугаа суллана. Хаялт, морины хөдөлгөөн дуусмагц дараагийн тоглогчийн ээлж автоматаар эхэлнэ. Цагаан хүрээ ээлжтэй морийг заана.
- Камер HTTPS эсвэл localhost / Live Server дээр ажиллана. Товчоор хаяж бас болно.

Морь/тэмээний талын хэлбэрийг эх OBJ загвараас илүү нарийвчлалтай авсан `race-bone.json` ашиглан харуулна. Хонхор гадаргуугийн сүүдрийг геометрээс тооцсон. Морьдын хоорондын зай 0.62 нэгж (өргөн нь ойролцоогоор 0.58), замын эгнээтэй мөн багахан зайтай.

## Эхлэх цэс

`index.html` нээхэд Алаг мэлхий болон Морь уралдуулах хоёр тоглоомын сонголт гарна. Алаг мэлхий `turtle.html`, уралдаан `race.html` хуудсанд байна. Тоглоом бүрийн «Тоглоом сонгох» холбоосоор эхлэх цэсэнд буцна. Уралдах морьд замын хоёр талаар ээлжлэн байрлана.

## Бичлэгийн шагайн дуу

Морь уралдуулахад хэрэглэгчийн илгээсэн бичлэгээс салгасан `shagai-throw.mp3` дуу тоглоно. Хаях хөдөлгөөн 2.65 секунд үргэлжилж, гол буулт дууны чанга мөргөлдөөнтэй таарна. Товч болон камерын хаялт ижил дуу ашиглана. Алаг мэлхий өөрийн өмнөх шооны дуутай.
